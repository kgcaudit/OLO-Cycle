# OLO 사이클 (OLO Cycle)

한 기기에서 **여러 가족 구성원의 생리 주기를 프로필로 구분해 관리**하는 Android 앱입니다.
달력법(calendar method)으로 다음 생리·배란·가임기를 추정합니다.

> 예측은 과거 기록을 평균한 **참고용 추정치**이며, 피임이나 진단의 근거가 아닙니다.

## 지금까지 구현 (0.2.0)

- **다중 프로필**: 구성원별 색상·기본 주기값·잠금 설정. 모든 기록은 `profileId`로 격리됩니다.
- **주기 예측 로직**(`cycle/CyclePredictor.kt`): 순수 Kotlin, 단위 테스트 10개
  - 최근 6주기 평균으로 주기 길이 산출(기록 3회 이상 시), 이상치(장기 미기록) 제외
  - 다음 예정일 = 마지막 시작일 + 평균 주기, 배란 = 예정일 − 14일, 가임기 = 배란 −5~+1일
  - 오늘이 지난 예정일은 자동으로 다음 주기로 롤포워드
- **홈 화면**(Jetpack Compose): 프로필 전환 바, 월간 달력(생리·예측·가임·배란·PMS 색 구분), D-day 카드, 구성원 추가 다이얼로그
- **일별 기록 입력**: 달력 날짜를 눌러 생리 시작일 지정 + 생리량·증상·기분·기초체온·메모 기록. 기록이 있는 날은 달력에 점으로 표시
- **로컬 저장**(Room): 기기 내부에만 저장, 인터넷 권한 없음
- **OLO 고유 디자인**: 플럼 + 코랄 브랜드 팔레트 (`ui/theme/Color.kt`)

날짜 칸을 누르면 기록 입력창이 열립니다. 여기서 생리 시작일을 켜면 예측이 즉시 갱신되고, 그날의 증상·기분 등도 함께 남길 수 있습니다.

## 빌드

JDK 17 + Android SDK(API 35) 필요.

```sh
./gradlew testDebugUnitTest   # 단위 테스트
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

푸시마다 GitHub Actions가 테스트·lint·디버그 APK 빌드를 실행합니다.
