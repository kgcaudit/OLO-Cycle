# OLO 사이클 (OLO Cycle)

한 기기에서 **여러 가족 구성원의 생리 주기를 프로필로 구분해 관리**하는 Android 앱입니다.
달력법(calendar method)으로 다음 생리·배란·가임기를 추정합니다.

> 예측은 과거 기록을 평균한 **참고용 추정치**이며, 피임이나 진단의 근거가 아닙니다.

## 지금까지 구현 (0.7.0)

- **다중 프로필**: 구성원별 색상·기본 주기값·잠금 설정. 모든 기록은 `profileId`로 격리됩니다.
- **주기 예측 로직**(`cycle/CyclePredictor.kt`): 순수 Kotlin, 단위 테스트 13개
  - 최근 6주기 평균으로 주기 길이 산출(기록 3회 이상 시), 이상치(장기 미기록) 제외
  - 다음 예정일 = 마지막 시작일 + 평균 주기, 배란 = 예정일 − 14일, 가임기 = 배란 −5~+1일
  - 오늘이 지난 예정일은 자동으로 다음 주기로 롤포워드
- **홈 화면**(Jetpack Compose): 프로필 전환 바, 월간 달력(생리·예측·가임·배란·PMS 색 구분), D-day 카드, 구성원 추가 다이얼로그
- **일별 기록 입력**: 달력 날짜를 눌러 생리 시작일 지정 + 생리량·증상·기분·기초체온·메모 기록. 기록이 있는 날은 달력에 점으로 표시
- **프로필 관리**: 헤더의 편집 버튼으로 이름·색상·평균 주기/생리 기간·피임약·잠금을 수정하고, 프로필 삭제(기록 함께 삭제) 가능. 아바타에 잠금 표시
- **OLO 디자인 시스템 채택**(crosspoint-reader `docs/design-handoff`): 클레이(#B95B3B)+아이보리 웜톤 역할색, 웜톤 단계색. 구성원은 아바타·타일 색으로만 구분(화면 강조는 클레이 하나)
- **실행 아이콘**: OLO 계열 공통 클레이 그라데이션 바탕 + 밝은 그레이 도형. 도형은 이 앱의 상징인 '순환 고리'(찢는 모티프 없음). 적응형·모노크롬·해상도별 PNG 포함
- **홈 재구성(주요 앱 학습 반영)**: 프로필을 헤더로 올리고, 홈에 **원형 주기 링**(단계·D-day) + **‘오늘 기록’** 버튼 + 큰 월간 달력. 링·달력·오늘 표시가 **프로필 색**을 따름(정=틸 등)
- **달력 칸 기호**(타 앱 참조): 예측 생리 = 점선 테두리(Apple·Flo), 배란 = ◯ 고리, 기록 항목은 칸 하단 색 점(생리량 물방울·증상 앰버·기분 틸·메모 그레이, Clue식). 기록 입력창 라벨에도 같은 색 점
- **하단 4탭**: 홈 · 기록(기록한 날 목록) · 통계(평균 주기·생리·규칙성·주기 추이·다음 예정) · 설정
- **프로필 잠금(실제 인증)**(`auth/BiometricAuth.kt`): 설정에서 잠금을 켠 프로필은 열 때 **생체인증 또는 기기 화면 잠금(PIN/패턴/비밀번호)**을 요구한다. 잠긴 프로필을 고르면 내용 대신 잠금 화면(LockGate)이 뜨고, 인증에 성공한 프로필만 그 세션 동안 열린다. 기기에 잠금 수단이 없으면 토글을 켜지 못하게 막고 안내한다. API 30+ 에선 생체+기기잠금을, 그 이하에선 생체인증을 쓴다. 인증만 하며 별도 비밀번호를 저장하지 않는다
- **프라이버시 전면화**: 설정 최상단에 “내 데이터는 이 기기에만 있습니다”(인터넷 권한 없음·추적 없음·계정 없음)
- **로컬 저장**(Room): 기기 내부에만 저장, 인터넷 권한 없음(권한은 프로필 잠금용 `USE_BIOMETRIC` 하나뿐)

날짜 칸을 누르면 기록 입력창이 열립니다. 여기서 생리 시작일을 켜면 예측이 즉시 갱신되고, 그날의 증상·기분 등도 함께 남길 수 있습니다.

## 빌드

JDK 17 + Android SDK(API 35) 필요.

```sh
./gradlew testDebugUnitTest   # 단위 테스트
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

푸시마다 GitHub Actions가 테스트·lint·디버그 APK 빌드를 실행합니다.
