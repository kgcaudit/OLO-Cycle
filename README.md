# OLO 사이클 (OLO Cycle)

한 기기에서 **여러 가족 구성원의 생리 주기를 프로필로 구분해 관리**하는 Android 앱입니다.
달력법(calendar method)으로 다음 생리·배란·가임기를 추정합니다.

> 예측은 과거 기록을 평균한 **참고용 추정치**이며, 피임이나 진단의 근거가 아닙니다.

## 지금까지 구현 (0.19.1)

- **"오늘" 표시 방식 개선(외부 사례 반영)**: 칸을 색으로 꽉 채우는 달력에서 오늘을 칸 전체 테두리로 표시하니 생리(채움) 칸 위에서 대비가 약해 안 보이던 문제. Google·Apple 관습대로 **날짜 숫자 뒤 구성원색 원 + 흰 숫자**로 바꿔 채움색·배란 고리와 무관하게 또렷하게. 홈 주간 스트립도 동일 규칙, 연 뷰의 오늘은 구성원색 solid 칸으로 통일.

## 이전 구현 (0.19.0)

- **복원 "합치기(merge)" 모드 추가**: 복원 시 **전부 대체(덮어쓰기)** 외에 **현재 데이터에 합치기**를 선택할 수 있다. 합치기는 이름이 같은 구성원은 그 구성원에 기록을 더하고(같은 날짜 기록은 기존 유지), 없는 구성원은 새로 추가한다.
- **뒤로 가기·잠금 흐름 정비**: 화면 상태(탭·설정)를 잠금 게이트보다 위에서 `rememberSaveable`로 보존 → 잠금/프로세스 재생성 후에도 이전 화면으로 복귀(설정에서 파일 선택 후 홈으로 튕기던 버그 수정). **파일 선택기(SAF) 사용 중에는 재잠금 억제**(정상 앱 내 작업). 시스템 **뒤로 가기**: 설정에선 설정 닫기, 달력·분석 탭에선 오늘로, 다이얼로그는 각자 닫힘.

## 이전 구현 (0.18.0)

- **암호화 백업 내보내기 / 복원**(`data/BackupCodec.kt`): 전체 데이터(구성원·생리기록·일별기록·프로필 사진)를 하나의 파일로 내보내고 복원. 파일은 사용자 비밀번호로 **AES-256-GCM** 봉인, 키는 **PBKDF2(HMAC-SHA256, 21만 회)**로 유도, 매 백업마다 새 salt·IV. 무결성(GCM 태그)까지 검증하므로 비밀번호가 틀리거나 파일이 변조되면 복호화가 거부된다. 저장·불러오기는 **시스템 파일 선택기(SAF)**로 이뤄져 저장소 권한이 필요 없고, 인터넷으로 나가지 않는다(원칙 유지). 복원은 현재 데이터를 백업 내용으로 대체(확인창). 설정 → 백업.

## 이전 구현 (0.17.0)

- **색 체계 전면 정리(B안·구성원 강조형)**: 한 화면에 8~9색이 깔리던 문제를 해결. 색의 축을 3개(브랜드·구성원·주기)→2개로 접음. **활성 구성원 색이 그 순간 앱 강조색**(히어로·활성 탭·FAB·오늘 표시·차트·KPI). 구성원 팔레트를 따뜻/중립 톤으로만 재구성해 **주기 의미색과 충돌 제거**(기존 틸 구성원색은 더스티 블루로 이관, DB 마이그레이션 v3).
- **주기 의미색 2극화**: 생리=웜 로즈(마젠타 기미 제거), 가임·배란=세이지 틸 한 색의 명도차(배란 별색 폐지), 예정일=로즈 옅은 톤+점선. 기록창은 **선택된 칩에만** 의미색(필드 점 남발 제거).
- **헤더 워드마크(3안)**: 순환 고리 마크 + `OLO`(클레이)`Cycle`(잉크) 워드마크를 위, 화면명을 아래 작은 글씨로 2단 배치 — 브랜드가 주인공.
- **홈 하단 정리**: "예측은 참고용…" 면책 문구를 홈에서 제거(앱 정보 창에 유지)하고 그 여백을 **"이번 주기 진행" 바**로 활용.

## 이전 구현 (0.16.1)

- **팝업(다이얼로그) 전면 OLO화**: 모든 창(기록 입력·구성원 편집·연월 선택·앱 정보)을 기본 Material 대신 OLO 웜톤 표면(아이보리+클레이 버튼)으로 통일. 제목은 상단, 확인/취소는 하단에 고정하고 본문만 스크롤하도록 재구성해 **하단 메모 입력칸이 잘리던 문제 해결**. 입력칸(OutlinedTextField)·스위치 색도 OLO 토큰으로 정리, 증상 라벨 점 색과 칩 선택색을 일치. 문구 정리(“프로필 편집→구성원 편집” 등), 미사용 코드 제거.

## 이전 구현 (0.16.0)

- **레이아웃 전면 재편(구성원 중심 3탭)**: 하단 탭을 **오늘·달력·분석** 3개 + 우측 ＋기록으로 단순화. 구성원 관리 통합(＋=추가, 활성 타일 탭=편집, 이름 중복 표기 제거). 설정 그룹화(보안·개인정보·앱). **증상 인사이트**(자주 나타난 증상·주기별 빈도)를 분석 탭에 로컬 집계로 추가. 하단 내용에 구성원 색 수직 라인을 붙여 누구의 정보인지 식별 용이.

## 이전 구현 (0.14.0)

- **달력 칸 정보 강화**(벤치마크 반영): 생리 칸에 **진행 일수(“N일”)**, 예측일 **“예정”**, 배란일 **“배란”** 라벨을 칸 안에 표기. 기록 점(생리량·증상·기분·메모)은 유지.
- **연(年) 달력 뷰**: 달력 탭 상단 **월/연 토글** → 12개월을 한 화면에 색으로 칠해 한 해 패턴 조망. 월을 누르면 그 달의 월간 달력으로.
- **주기 히스토리 표**(통계): 기록된 **생리 구간(기간) + 다음까지의 주기 길이**를 최근 것부터 표로.
- **상단 구성원 스위처 컴팩트화** + **달력 무스크롤**(한 화면에 꽉 채움, 하단 안내문구 제거) + **PMS 구간 색 연하게**.

## 이전 구현 (0.12.0)

- **새 GUI 프레임(구성원 중심)**: 화면 **최상단에 구성원 스위처 고정**(활성은 크게·색 링, 나머지는 작게, ＋추가, 우상단 ⚙설정·연필편집) → 모든 화면 공통 앵커. 하단은 **홈·달력·기록·통계 4탭 + 가운데 ＋기록 FAB**. **설정은 탭에서 빼 전역 전체화면(⚙)**으로 분리.
- **홈 = 대시보드**: 구성원색 상태 히어로(단계·D-day·미니 링) + 오늘 기록 버튼 + **다가오는 일정**(다음 생리·배란·가임기 D-day) + **이번 주 스트립**(단계색·오늘 강조, 누르면 달력).
- **달력 = 독립 전체화면 탭**: 크게 보이는 월간 달력 + 칸 기호 + 범례(좁던 문제 해소).
- **다중 프로필**: 구성원별 **사진·색상**·기본 주기값. 모든 기록은 `profileId`로 격리됩니다.
- **구성원 이동**: 상단 아바타 탭 또는 **좌우 스와이프**로 전환(전환 시 이동 방향에서 **슬라이드+페이드** 애니메이션).
- **작업 전환 화면 가리기**: 최근 앱(멀티태스킹) 미리보기에 기록 내용이 남지 않게 가림. API 33+ 는 미리보기만 끄고 사용자의 직접 스크린샷은 허용(`setRecentsScreenshotEnabled`), 그 이하는 `FLAG_SECURE`
- **프로필 사진**(`data/ProfilePhotos.kt`): 시스템 사진 선택기로 고른 이미지를 앱 내부 저장소로 **복사·축소(최대 512px)**해 두고 경로만 DB에 기록. 저장소 권한 없이 동작하고 인터넷으로 나가지 않는다. 헤더·구성원 목록·편집창 아바타가 사진(없으면 색+이니셜)으로 통일. 프로필/사진 삭제 시 파일도 정리
- **설정/프로필 역할 분리**: 설정 탭은 **앱 전체 공통 항목만**(프라이버시·앱 잠금·앱 정보). 이름·사진·색상·주기 등 **개인별 설정은 각 프로필(상단 연필 편집창)**에 모음
- **주기 예측 로직**(`cycle/CyclePredictor.kt`): 순수 Kotlin, 단위 테스트 13개
  - 최근 6주기 평균으로 주기 길이 산출(기록 3회 이상 시), 이상치(장기 미기록) 제외
  - 다음 예정일 = 마지막 시작일 + 평균 주기, 배란 = 예정일 − 14일, 가임기 = 배란 −5~+1일
  - 오늘이 지난 예정일은 자동으로 다음 주기로 롤포워드
- **홈 화면**(Jetpack Compose): 프로필 전환 바, 월간 달력(생리·예측·가임·배란·PMS 색 구분), D-day 카드, 구성원 추가 다이얼로그
- **일별 기록 입력**: 달력 날짜를 눌러 생리 시작일 지정 + 생리량·증상·기분·기초체온·메모 기록. 기록이 있는 날은 달력에 점으로 표시
- **프로필 관리**: 헤더의 편집 버튼(또는 설정 → 구성원)으로 사진·이름·색상·평균 주기/생리 기간·피임약을 수정하고, 프로필 삭제(기록·사진 함께 삭제) 가능
- **OLO 디자인 시스템 채택**(crosspoint-reader `docs/design-handoff`): 클레이(#B95B3B)+아이보리 웜톤 역할색, 웜톤 단계색. 구성원은 아바타·타일 색으로만 구분(화면 강조는 클레이 하나)
- **실행 아이콘**: OLO 계열 공통 클레이 그라데이션 바탕 + 밝은 그레이 도형. 도형은 이 앱의 상징인 '순환 고리'(찢는 모티프 없음). 적응형·모노크롬·해상도별 PNG 포함
- **홈 재구성(주요 앱 학습 반영)**: 프로필을 헤더로 올리고, 홈에 **원형 주기 링**(단계·D-day) + **‘오늘 기록’** 버튼 + 큰 월간 달력. 링·달력·오늘 표시가 **프로필 색**을 따름(정=틸 등)
- **달력 칸 기호**(타 앱 참조): 예측 생리 = 점선 테두리(Apple·Flo), 배란 = ◯ 고리, 기록 항목은 칸 하단 색 점(생리량 물방울·증상 앰버·기분 틸·메모 그레이, Clue식). 기록 입력창 라벨에도 같은 색 점
- **하단 4탭 + FAB**: 홈(대시보드) · 달력 · 기록(기록한 날 목록) · 통계(평균 주기·생리·규칙성·주기 추이·다음 예정), 가운데 ＋기록 FAB. 설정은 상단 ⚙
- **앱 잠금(실제 인증)**(`auth/BiometricAuth.kt`): 프로필별이 아니라 **앱 전체 한 개**의 잠금. 설정에서 켜면 **첫 구동 때, 그리고 홈·다른 앱으로 나갔다 돌아올 때마다** 잠금 화면(AppLockGate)이 뜨고 **생체인증 또는 기기 화면 잠금(PIN/패턴/비밀번호)**을 요구한다. 잠금 화면에선 앱 내용이 전혀 보이지 않는다. 재잠금은 `ON_STOP`(회전 등 구성 변경은 제외), **인증창 자동 표시는 앱이 실제로 앞으로 돌아온 `ON_RESUME`**에 건다(백그라운드에서 띄우면 인증창이 못 떠 수동 버튼만 남던 문제 수정). 취소 시 버튼으로 재시도. 인증창(기기 잠금)으로 잠깐 나간 사이에는 다시 잠기지 않도록 처리. 기기에 잠금 수단이 없으면 토글을 켜지 못하게 막고 안내한다. API 30+ 에선 생체+기기잠금을, 그 이하에선 생체인증을 쓴다. 인증만 하며 별도 비밀번호를 저장하지 않는다
- **프라이버시 전면화**: 설정 최상단에 “내 데이터는 이 기기에만 있습니다”(인터넷 권한 없음·추적 없음·계정 없음)
- **로컬 저장**(Room): 기기 내부에만 저장, 인터넷 권한 없음(권한은 프로필 잠금용 `USE_BIOMETRIC` 하나뿐)

날짜 칸을 누르면 기록 입력창이 열립니다. 여기서 생리 시작일을 켜면 예측이 즉시 갱신되고, 그날의 증상·기분 등도 함께 남길 수 있습니다.

## 빌드

JDK 17 + Android SDK(API 35) 필요.

```sh
./gradlew testDebugUnitTest   # 단위 테스트
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

푸시마다 GitHub Actions가 테스트·lint·디버그 APK 빌드를 실행합니다.
